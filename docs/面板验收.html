AppleEmojiSwitcher · Emoji 17.0 原生面板验收

计划版本：1.3.0（开发中） · 状态：development-manual-pending

本页只记录你在 Windows 原生 Win＋句号面板中亲自看到、搜索和点击输入的结果。

边界：这是离线验收工作表，不是表情输入器、复制工具或面板替代品。 页面不会访问网络、写入剪贴板、请求权限或自动勾选任何观察结果。字体能显示表情、目录中有名称，均不能单独证明原生面板支持。 当前原生注入控制器和登录激活尚未可用；panel.cmd 命令是后续接入约定，不能据此声称面板已扩展。

使用顺序

  1. 控制器接入后，在仓库目录按需运行 panel.cmd status；准备验收时运行 panel.cmd enable。当前命令仅为待接入约定。
  2. 打开 Windows 原生面板：按 Win＋.。逐条按分类、中文搜索、英文搜索和点选输入检查。
  3. 点选后，把原生面板实际输入到记事本或 Edge 的字符手动粘贴到对应“实际输入”框。页面只比较完整 Unicode 字符串，不会替你复制。
  4. 只有亲自看到分类或搜索结果时，才勾选对应证据框；未勾选表示没有记录，不等同于“确认不支持”。正式序列和简化序列必须分别记录。
  5. 完成下方整体验收门后，勾选“我确认本报告来自本机原生面板”，再导出 JSON。默认状态永远是待验收。

整体验收门

每一项都需要你在本机完成后再勾选；证据说明栏可写日期、应用窗口或失败原因。空白项目会以 pending 导出。

停用与卸载命令

控制器接入并完成验收后，可按需运行 panel.cmd disable 停用，或运行 panel.cmd uninstall 清理面板扩展及登录项。panel.cmd status 仅查看状态。当前这些命令尚未构成可用控制器；字体安装、原始备份和恢复事务按各自说明处理。
