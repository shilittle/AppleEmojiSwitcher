# v1.3.0 增强面板验收

自动检查与实际应用检查分别记录，不以字体覆盖率替代快捷键和输入结果。

1. 在普通权限记事本输入框按 Win + .，确认仅打开增强面板。
2. 搜索“笑”、`distorted face`、`1FAEB`；检查分类、Emoji 18 最新项和肤色。
3. 输入普通 Emoji、18.0 新项、肤色、职业 ZWJ、国旗、键帽和方向组合，比较完整字符串。
4. 在浏览器文本框重复。字体缺字时核对码位，记录为“输入通过、目标显示缺字”。
5. Esc 收起；普通句号、分号及带 Ctrl/Alt/Shift 的组合不被拦截；再次打开后可直接搜索。
6. 仅主动点击“复制”改变剪贴板；普通插入、失败和取消不覆盖剪贴板。
7. 打开原生面板检查可用；退出增强面板后 Win + . 恢复系统行为。
8. 启用、重复启用、停用、重新启用和卸载，检查单实例、启动项与实际进程。

实际完成项写入 `PANEL-VALIDATION.md`；未检查的应用不得标成通过。
