# Emoji 18.0 增强面板 · v1.3.0

不升级 Windows 即可使用完整 Emoji 18.0 选择目录。包含 3,963 项和离线彩色预览，支持中文、英文、Unicode 码位搜索，以及分类、最新、最近使用。

## 启动

解压后双击 `表情面板.vbs`。运行期间 Win + . 和 Win + ; 打开增强面板；关闭面板窗口后留在托盘，托盘“退出”释放快捷键。

在目标输入框中按快捷键，选择表情后点击或按 Enter。程序将完整 Unicode 序列发送回原窗口，保留肤色、ZWJ 和变体选择符。Esc 收起面板；“复制”是显式操作，普通插入不读写剪贴板。

## 登录启动与停用

| 命令 | 行为 |
| --- | --- |
| `panel.cmd enable` | 安装到当前用户目录，注册登录启动，立即启用 |
| `panel.cmd status` | 查询实际运行和安装状态 |
| `panel.cmd disable` | 停止增强面板并取消登录启动 |
| `panel.cmd uninstall` | 停用并移除面板文件 |

`panel.cmd` 无参数显示中文菜单。完整字体 GUI 也提供启用、停用和状态按钮。无需管理员权限，无需重启。

安装位置为 `%LOCALAPPDATA%\AppleEmojiSwitcher\panel`。卸载不删除原有字体、字体缓存或 `%ProgramData%\AppleEmojiSwitcher` 下的恢复备份。

## 显示与兼容性

预览采用苹果图案，缺项由 Noto 补齐。图片只用于选择，实际输入为标准 Emoji 字符。目标应用和接收端的字体决定最终外观，可能与面板不同。固定苹果字体的 Emoji 17 覆盖与面板的 Emoji 18 输入目录是两个独立能力。

程序使用当前用户的键盘钩子处理指定快捷键，不注入 Windows 输入宿主，不替换系统组件。系统原生面板可从面板/托盘入口打开；停用或退出后，Win + . 恢复原有行为。

管理员应用可能拒绝普通权限程序发送的输入。焦点恢复失败时会提示错误，可显式复制后自行粘贴。系统安全桌面、游戏原始输入及特殊控件不在自动插入保证范围。
